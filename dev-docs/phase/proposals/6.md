# Phase 6: Login and scoreboard

Goal: accounts and leagues.

## Steps

- backend in /backend with a database (users, scores, streaks)
- login: email magic link (no passwords)
- sync streaks and round scores to the account
- scoreboard page: login required to view and participate
- "Bronze League": ranking of users by score
  - flavor text: compete against toddlers and people who still hold up their index finger and thumb to check which way is left
- scores submitted after each round when logged in

## Done when

- user can log in, play, and appear on the Bronze League board
- logged-out user sees a login prompt on the scoreboard
