# Phase 3: Remaining image reaction games

Goal: all image reaction minigames, plus a way to choose among them.

## Steps

- image reaction prompts: something points left/right, or an obvious question like "Your heart is in the ____ side"
- Typing: type "left"/"right"
- Unlabeled Button: click one out of two identical buttons side by side
- Audio: speak "left"/"right" (speech recognition, with mic permission handling)
- game picker: round picks a random minigame, or user chooses one

## Done when

- every image reaction game is playable and returns a score
- denied mic permission shows a clear message and falls back to another game
