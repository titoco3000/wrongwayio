# Phase 7: Premium gifts

Goal: users "buy" 30 days of premium for friends. It is free, login required.

## Steps

- gift page (login required): user either
  - enters the friend's email, and/or
  - generates an invite magic link
- store gift: giver, friend email, 30 days, status
- email to friend: "Your friend <friend_name> has gifted you 30 days of premium WrongWayio access! It starts now. It would be rude not to partake your lessons"
- same message shown on first login if the friend has a pending gift
- magic link redeems the gift after login
- premium flag with expiry date on the user, 30 days from redemption
- gifts can be redeemed once only

## Done when

- gift by email reaches the friend and activates premium on first login
- gift by link activates premium for whoever opens it and logs in
- premium expires after 30 days
