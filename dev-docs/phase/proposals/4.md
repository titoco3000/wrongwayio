# Phase 4: Word reaction games and settings

Goal: word reaction games, with accessibility and difficulty settings.

## Steps

- word prompt: randomly either text appears or audio plays "left"/"right"; user must react quickly
- Button: click one out of two identical buttons side by side
- Sorting: a box falls from the top, user drags it to the right or left bin
- Driving: user controls a steering wheel to turn the car to the correct direction
- settings page (StackPage):
  - text-only option (no audio)
  - difficulty: reaction speed
- settings saved in local storage and applied to all word reaction games

## Done when

- all three word reaction games are playable and return a score
- text-only setting stops all audio
- difficulty changes reaction time visibly
