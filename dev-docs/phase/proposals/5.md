# Phase 5: Streaks

Goal: daily streak tracking with sassy messages.

## Steps

- record a day as done when user finishes a round with a passing score
- streak counter: consecutive days
- streak message on success: "You've correctly identified your left hand for 3 days in a row! Don't ruin it now."
- streak message on a missed day: "Looks like you forgot your left from your right today. I guess we're walking into traffic now."
- show messages in a SpeechBubble with the pigeon mascot
- store locally for now (synced to the account in phase 6)

## Done when

- finishing rounds on consecutive days increases the streak
- skipping a day resets it and shows the missed-day message
