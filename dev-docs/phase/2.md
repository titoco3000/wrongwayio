# Phase 2: Game

Goal: first playable minigame, reachable from a "play round" button.

## Steps

- On homepage, two returnable stack pages: demo and gamePage. Each has its own stack. 
- generic MiniGame component, with `onEnd`
  - plays on loop a fixed amount of times
  - on end, calls `onEnd` with score: amount correct and total
- component to display the direction the user is supposed to press
- Image reaction game: Labeled Button (click on randomly-ordered "left"/"right" buttons)
- StackPage with button "play round": closeable page with the game
- score logged after the last round and game closed

## Done when

- user can open a round, play all loops and score is logged to console
- closing the page mid-game removes it from the stack
