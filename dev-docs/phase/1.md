# Phase 1: Basic UI building blocks

Goal: a frontend with all reusable pieces, shown on a demo page.

## Steps

- vite + react + tailwind app in /frontend
- global styles: main color scheme in gray/black/white/red/blue, font
- splash screen with icon (pigeon) fading to page
- PagesStack: holds a stack of pages, renders the top one
- StackPage: page with either a back arrow (removes itself from the stack) or a close button (removes all pages from the stack)
- ButtonsRow & Button: `onSubmit` in ButtonsRow with `value` as argument
- Select & Option: `onChange` in Select with `value` as argument
- Container: receives header, body and footer. All children are placed inside an element with max width, centered. Header and footer always visible, fills device height. Body fills remaining space, scroll auto
- SpeechBubble: comic-book-style, connecting to the left or right, with text
- HomePage: shows button to take to Demo page
- Demo page: shows every component above and arrow to go back to home. Demo has its own stack.

## Done when

- app runs with `npm run dev`
- demo page shows every component working
- pages can be pushed, popped and closed through PagesStack
