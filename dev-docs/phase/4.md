# 4 - Daily challenge

Lets implement a daily challenge.

A button "daily challenge" takes to a page you can close.

5 minigames are chosen randomly (without repeating). The random seed is based on the date.

User needs to complete them back to back. 

On completion / failure, the info is saved locally.

The button changes to "daily challenge done/failed!". Clicking on it shows a popup asking if the user whant to repeat it - but the button state wont change.
