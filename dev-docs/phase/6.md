# 6 - user profiles

Lets create a user profile page and the premiun account system.

Firstly, add a stub api system.

In the homepage, instead of the theme toggle, a user profile icon. Clicking it opens the user profile page.

If the user is not logged in, there should be a button to login or create account. 

On account creation, just ask for a name and use the api to check if there is already someone with that name.

Upon confirmation, say the account is oficialy created.

For login, ask for the name again. If the name is not found on the API, offer to create and take to the creation page, with the name pre-filled. If found, ask for the person to pinky promise they are who they claim they are, because we have no passwords. We work here in the honor system.

If a user has a premium pass, it should show in a flashy banner under their name, with the amount of time they have left.

If logged in, there should be an option to buy a premium pass for a friend. A page with the perks of the plan: 

- a flashy banner
- bragging rights
- peer presure
- honor
- glory
- ...

After confirming our friend deserves it, take to a page with a copy-field with the website URL plus some url parameters informing the origin of the premium pass.

The theme togle is also in the profile page, together with any future configs.
